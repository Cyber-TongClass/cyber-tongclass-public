# 课题组成果与教师页面精简设计

## 范围

调整公开课题组详情页中的“相关成果”列表，并精简教师个人详情页。学生及其他成员的个人页面保持不变。

## 展示

课题组页面不显示成果摘要。成果标题链接不显示下划线，但继续保留现有文字颜色、悬停变红和键盘焦点轮廓。成果类型、年份、标题、列表分隔线和空状态保持不变。

教师个人详情页显示身份、姓名、职务、Coffee Talk 入口、个人简介和研究方向。研究方向之后不再显示“相关团队”“相关成果”“相关团队的公开研究生”和“相关动态”，避免与教师课题组页面重复。

## 实现

为共享成果列表增加显式展示选项，由课题组详情页关闭摘要和标题下划线；默认值保持当前行为，避免影响其他成果列表。

人员详情组件根据人员类别判断：仅教师在研究方向后结束页面，其他人员继续沿用现有相关内容区域。

## 验证

增加源码契约测试，确认课题组页面传入精简选项、共享组件默认仍显示摘要和下划线，并确认只有教师隐藏研究方向之后的内容。运行定向测试、ESLint、TypeScript，并在本地页面进行视觉冒烟检查。
